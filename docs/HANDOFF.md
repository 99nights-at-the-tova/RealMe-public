# 開発引き継ぎ

更新日: 2026-11-19

RealMeはAndroid向けのオフラインMVPです。Kotlin / Jetpack Compose、DataStore、WorkManagerを使用します。現状の投稿は端末内に保存され、他の端末との同期はありません。

## 現在の実装

- ゲーム画面のスクリーンショット検知と投稿確認通知、クイック設定からの撮影。
- 画像編集、端末内タイムライン、自動投稿、プライバシー画像。
- ローカルアカウントのPIN、アカウント削除とクリーンアップの再試行。
- イベントのランダム通知と端末間共有は未実装。Supabase / Firebase / FCMは未接続。
